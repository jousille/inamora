# Инструкция по редактированию сайдбара

*Блог Юли Инаморы · статьи в формате HTML*

---

## 1. Где найти сайдбар в файле

Откройте нужный HTML-файл статьи в любом текстовом редакторе (VS Code, Sublime Text, Notepad++). Найдите тег:

```html
<aside class="article-sidebar">
```

Он находится сразу после закрывающего тега `</main>`. Весь сайдбар — три карточки подряд — лежит внутри этого блока.

Структура выглядит так:

```html
</main>

<aside class="article-sidebar">

  <div class="sidebar-card"> ... </div>       ← карточка 1
  <div class="sidebar-card" ...> ... </div>   ← карточка 2
  <div class="sidebar-card" ...> ... </div>   ← карточка 3

</aside>
```

---

## 2. Что менять внутри карточки

Каждая карточка состоит из четырёх элементов. Ниже — где именно каждый из них находится в коде:

**Подпись сверху (рубрика / тип продукта)**
```html
<p style="font-size:.65rem;color:#B58E8E ...">Бесплатно · PDF для печати</p>
```

**Заголовок**
```html
<h4>Планер энергетического баланса</h4>
```

**Описание**
```html
<p>Распечатайте и заполняйте от руки. 28 дней.</p>
```

**Цена**
```html
<div class="sidebar-price" style="color:#B58E8E">Бесплатно</div>
```

**Кнопка**
```html
<a href="../products/free/planer.html" style="...">Скачать PDF ↓</a>
```

В кнопке меняйте: `href` (куда ведёт), текст внутри тега, и при необходимости стили.

---

## 3. Цвета карточек

Фон и рамка каждой карточки задаются в атрибуте `style` на открывающем теге `<div class="sidebar-card">`:

**Карточка 1 — белая (по умолчанию):**
```html
<div class="sidebar-card">
```
*Фон и рамка берутся из CSS-класса. Менять не нужно.*

**Карточка 2 — светло-розовый фон, акцентная рамка:**
```html
<div class="sidebar-card" style="background:var(--light);border-color:var(--accent)">
```

**Карточка 3 — тёмный фон:**
```html
<div class="sidebar-card" style="background:#3D2E2E;border:1px solid #3D2E2E">
```
*Цвет текста внутри третьей карточки нужно делать светлым — `#FBF7F7`, `#D4B8B8` или `#EDD8D8`.*

---

## 4. Цветовая палитра сайта

Переменные и их значения — можно использовать везде в `style="..."`:

| Цвет | Переменная | HEX | Применение |
|------|------------|-----|------------|
| 🟫 | `var(--dark)` | `#3D2E2E` | Тёмно-коричневый · фон карточки 3, заголовки |
| 🟤 | `var(--dark-mid)` | `#6B4E4E` | Средний · основной цвет текста |
| 🌸 | `var(--accent)` | `#B58E8E` | Розово-бежевый · рамки, кнопки, ссылки |
| 🌷 | `var(--accent-lt)` | `#D4B8B8` | Светлее accent · кнопка карточки 1 |
| 🩷 | `var(--mid)` | `#EDD8D8` | Розовый · фоны блоков callout |
| 🌺 | `var(--light)` | `#F5ECEC` | Светло-розовый · фон карточки 2 |
| 🤍 | `var(--lighter)` | `#FBF7F7` | Почти белый · фон страницы |

---

## 5. Цвет текста внутри карточек

Цвет каждого текстового элемента задаётся прямо в его `style="color:..."`. Рекомендации:

| Элемент | Карточки 1–2 (светлый фон) | Карточка 3 (тёмный фон) |
|---------|---------------------------|------------------------|
| Подпись сверху | `#B58E8E` | `#D4B8B8` |
| Заголовок `<h4>` | `#3D2E2E` (по умолчанию) | `#FBF7F7` |
| Описание `<p>` | `#6B4E4E` (по умолчанию) | `#D4B8B8` |
| Цена `.sidebar-price` | `#B58E8E` или `#3D2E2E` | `#EDD8D8` |
| Кнопка `<a>` | `var(--accent)` / `#D4B8B8` | `#D4B8B8` пунктир |
